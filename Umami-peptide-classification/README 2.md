# Umami peptide classification dataset

## What is this dataset?

This dataset contains food-derived peptide sequences labelled as umami or bitter/non-umami. It can be used to develop models that identify peptides with potential umami taste, which are of interest as food flavour enhancers.

## Dataset files and size

The supplied dataset is split into a training set and an independent test set:

| File | Records | Umami (`0`) | Bitter/non-umami (`1`) |
| --- | ---: | ---: | ---: |
| `umami_MRNN_train.xlsx` | 400 | 170 | 230 |
| `umami_MRNN_test.xlsx` | 100 | 42 | 58 |
| **Total** | **500** | **212** | **288** |

The workbooks contain 500 unique peptide sequences. The supplied test file contains 100 records; this is one more non-umami record than the 99-record test split reported in the accompanying paper.

## Input and output

| Field | Role | Description |
| --- | --- | --- |
| `sequence` | Input | Peptide sequence, written using one-letter amino-acid codes. |
| `label` | Output | Binary taste class: `0` = umami peptide and `1` = bitter/non-umami peptide. |

This is a **sequence-to-classification** dataset: predict whether a peptide has an umami or bitter/non-umami label from its sequence, or from features or representations derived from its sequence.

## Using this dataset in assignments

This dataset can be used for **Assignment 1**, **Assignment 2**, and the **Final Project**. It supports binary classification using traditional sequence-derived features and machine-learning classifiers, or representations generated by a scientific protein language model.

The provided training and test files should be retained as separate splits. Students may use a further validation split or cross-validation within the training data, but should not use the independent test set for model selection. Appropriate evaluation measures include accuracy, precision, recall, F1 score, Matthews correlation coefficient, and a confusion matrix.
