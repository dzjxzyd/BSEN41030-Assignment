# Cell-penetrating peptide classification dataset

## What is this dataset?

This dataset contains peptide sequences labelled according to whether they are cell-penetrating peptides (CPPs). CPPs can cross cell membranes and are of interest for intracellular delivery of therapeutic cargoes, such as small molecules, nucleic acids, and proteins.

## Dataset files and size

The dataset is supplied in two Excel workbooks:

- `pLM4CPPs_dataset_CPP.xlsx`: **1,380** peptide records.
- `pLM4CPPs_dataset_Non-CPP.xlsx`: **4,099** peptide records.

Together, the files contain **5,479 unique peptide sequences**: **1,399 CPPs** (label `1`) and **4,080 non-CPPs** (label `0`). Although the second file is named `Non-CPP`, it includes 19 CPP records (label `1`); use the `label` column, rather than the file name, to identify the class of every record.

## Input and output

| Field | Role | Description |
| --- | --- | --- |
| `sequence` | Input | Peptide sequence, written using one-letter amino-acid codes. |
| `label` | Output | Binary cell-penetrating-peptide class: `1` = CPP and `0` = non-CPP. |

This is a **sequence-to-classification** dataset: predict whether a peptide is a CPP from its sequence, or from features or representations derived from its sequence.

## Using this dataset in assignments

This dataset can be used for **Assignment 1**, **Assignment 2**, and the **Final Project**. It supports a binary classification task. Students can use traditional sequence-derived features and machine-learning classifiers, or representations generated by a scientific protein language model.

The classes are imbalanced (1,399 CPPs and 4,080 non-CPPs). Students should create training, validation, and test splits before model selection, or use cross-validation within the training data, and report accuracy, precision, recall, F1 score, Matthews correlation coefficient, balanced accuracy, and a confusion matrix.
